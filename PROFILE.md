# DietlyAPI

Food & nutrition data REST API with 4.2M+ foods, calories, macros, 17 micronutrients, barcode lookup, and confidence-ranked full-text search. Data primarily from Open Food Facts (ODbL), EU-hosted, with key-optional read access.

- **Provider:** https://www.getdietly.com/api
- **Documentation:** https://www.getdietly.com/api-guide
- **Base URL:** https://api.getdietly.com
